Release note languages

Approving a release writes one note per audience in each of these languages. Summaries are written in en; other languages are translated after approval, and a release is published only when every note is ready.

No translation provider is configured, so notes in other languages cannot be translated. Set RELEASEFLOW_TRANSLATION_PROVIDER=deepl and RELEASEFLOW_DEEPL_API_KEY, or edit those notes by hand.

Operator

A shipped audience. Its code is fixed; you can rename it, change its intent, or rewrite its template, and reset it to the shipped version at any time.

The code identifies the audience to the AI and in downloaded file names. It cannot change later.

Code operator

Mustache renders one change as Markdown. A section such as {{#narrative}}…{{/narrative}} is left out when the value is empty.

Language templates

Notes in these languages use their own template, so fixed words such as labels can be written in that language. The main template above is used for every other language.

Reset to preset

The name, intent, and template return to the shipped version in the Organization's output language, and each language template to the shipped version in its language. Notes already written keep the template they were written with.

Delete audience

This cannot be undone. An audience that already has release notes, or the last remaining audience, cannot be deleted.
